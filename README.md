# Fifa World Cup 2026 Analysis

## Project Overview

This project analyzes Fifa World Cup 2026 match, team, player, and event data using Python and Excel.

The aim is to identify important patterns in team performance, player performance, match outcomes, goals, xG, possession, shots, and match events.

## Research Questions

1. Which teams scored the most goals, and which conceded the fewest?
2. How are shots, shots on target, possession and xG related to match outcomes?
3. Which players had the strongest goal, assist and overall statistical performance?
4. How did team performance differ between the group and knockout stages?
5. Is xG a useful indicator of actual goals?
6. Do possession and shot volume correspond with winning more matches?
7. What match and event patterns stand out for cards, penalties and goals?
8. Which variables are most useful for predicting match outcomes?

## Tools Used

- Python
- Pandas
- Matplotlib
- Seaborn
- Excel
- GitHub
- Power BI

## Analysis

The project includes visual analysis of:

- Team goals and performance
- Player goal contributions
- xG and actual goals
- Possession and shots
- Group vs knockout stage performance
- Match events
- Cards, penalties and VAR reviews
